# Good Mood Burgers

Site responsivo de restaurante, feito com HTML, CSS e JavaScript.

## Funcionalidades

- Navegação adaptada a ecrãs pequenos, com suporte para teclado.
- Animações de entrada e efeitos de interação, respeitando a preferência por movimento reduzido.
- Secções de ingredientes, menu, entrega e contacto.
- Seleção demonstrativa de hambúrgueres, mantida apenas na página.

## Utilização

Abra `index.html` num navegador. A seleção de artigos é apenas uma demonstração: não existe processamento de encomendas nem recolha de dados ou pagamentos.

O projeto foi inspirado no tutorial [Responsive Burger Website](https://youtu.be/PA-V-GxYa9w), de [Bedimcode](https://www.youtube.com/@Bedimcode).
